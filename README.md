# MCHAWE SPORTS

تطبيق أندرويد رياضي باللغة العربية، مبني باستخدام Kotlin وواجهات Android Native.

## الميزات الحالية
- واجهة عربية باتجاه RTL.
- عرض مباريات كرة القدم من واجهة football-data.org API v4.
- تصنيفات: الكل، مباشرة، قادمة، منتهية، مؤجلة/ملغاة، والمفضلة.
- البحث عن فريق أو بطولة.
- تفاصيل المباراة والنتيجة والملعب وموعد بغداد.
- حفظ المفضلة ومفتاح API محلياً على الجهاز.
- عرض وقت آخر تحديث ومعالجة أخطاء الاتصال ومفتاح API وحدود الطلبات.
- GitHub Actions لبناء APK تجريبي عند كل Push إلى main أو يدوياً.

## ربط مصدر البيانات
1. أنشئ حساباً في https://www.football-data.org/client/register
2. انسخ مفتاح API.
3. افتح التطبيق وألصق المفتاح في نافذة الربط.

تختلف البطولات المتاحة حسب خطة مزود البيانات. لا تضع مفتاح API في ملفات المستودع أو تشاركه علناً.

## البث
يتضمن المشروع أساس مشغل Media3 / ExoPlayer، لكنه لا يحتوي على قنوات أو روابط بث مدمجة. لا تستخدم إلا روابط HLS/MP4 التي تملك حق استخدامها أو ترخيص توزيعها.

## البناء
ينتج GitHub Actions نسخة Debug APK للاختبار وليست إصداراً منشوراً على Google Play.
يتطلب البناء JDK 17 وGradle 8.9:
```bash
gradle assembleDebug
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`
