# MCHAWE SPORTS

تطبيق أندرويد رياضي باللغة العربية، مبني باستخدام Kotlin وواجهات Android Native.

## الموجود في النسخة الأولية
- واجهة عربية باتجاه RTL.
- تصنيفات: الكل، مباشرة، قادمة، منتهية.
- بطاقات مباريات تجريبية.
- اعتماد Media3 / ExoPlayer كأساس للمشغل.
- GitHub Actions لبناء APK تجريبي عند كل Push إلى main أو يدوياً.

## ملاحظات مهمة
- أسماء المباريات والتوقيتات الحالية بيانات تجريبية وليست جدولاً مباشراً.
- لا توجد حالياً خدمة API للنتائج أو روابط بث مدمجة.
- لتشغيل المشغل يجب توفير رابط بث HLS/MP4 تملك حق استخدامه أو لديك ترخيص لتوزيعه.
- APK الناتج نسخة Debug للاختبار، وليس إصداراً منشوراً على Google Play.

## البناء
يتطلب JDK 17 وGradle 8.9:
```bash
gradle assembleDebug
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`
